📚 Understanding the Metrics

These metrics help evaluate how well the AI model predicts food demand.

📏 MAE

Mean Absolute Error measures the average difference between the predicted food demand and the actual food demand.

📊 MSE

Mean Squared Error calculates the average squared difference between predicted and actual values.

📉 RMSE

Root Mean Squared Error shows the typical prediction error of the machine learning model.
